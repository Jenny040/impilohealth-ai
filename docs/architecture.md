# Architecture

Angular frontend → Spring Boot API → MySQL + Redis, with an AI services layer (Gemini in dev; Huawei Pangu NLP, HiLens Vision, ModelArts in production). Deployed on Huawei Cloud (ECS, RDS, DCS, CCE), Johannesburg region (af-south).
