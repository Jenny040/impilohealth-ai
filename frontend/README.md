# Frontend — Angular

Generate the project in this folder:

```bash
cd frontend
npx @angular/cli new impilohealth-web --directory . --routing --style=scss
```

Suggested layout (`src/app/`):

```
core/        auth, interceptors, guards, services
shared/      reusable components
features/
  home/  health-chat/  mood/  cycle/  shop/
  donation/  nutrition/  community/  profile/
```

Brand: Purple `#9C27B0`, Pink `#E91E8C`, Background `#FFF5F9`, font Poppins.
